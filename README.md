# 별을 세어 은하를 그리다 — 허셜의 별 계수법 시뮬레이터

중학 과학 '우리은하' 수업용 웹 시뮬레이터입니다. 학생은 먼저 짧은 튜토리얼(미션 4개)로 허셜의 규칙·가정과 '별의 수 ↔ 깊이' 관계를 익힙니다. 그다음 언덕 위에 서서 망원경을 수평선 쪽 12방향(30° 간격)으로 돌려 별을 세고, 지도에서 그 방향의 깊이를 골라 점을 찍어 은하의 단면을 그립니다. 나머지 하늘은 자동으로 별을 세어 3D 원반 지도를 완성하고, 선택형 문제 7개로 결과를 해석합니다. 마지막 문제에서 오늘날 알려진 우리은하와 비교합니다.

- 허셜의 가정(별은 고르게 분포, 은하 끝까지 관측 가능, 태양은 은하 중심)을 그대로 따릅니다. 실제 은하와의 차이는 수업에서 다룹니다.
- 스마트폰·태블릿 가로 화면 기준. 빌드 도구 없이 정적 파일만으로 동작합니다.

## 구성

| 경로 | 내용 |
|---|---|
| `app/` | 시뮬레이터 (`app/index.html`) |
| `app/js/config.js` | 화면 문구, 튜토리얼 문구, 해석 문제·보기·해설, 자동 세기 기준(10개) — 선생님이 직접 고칠 수 있음 |
| `worksheet/` | 종이 활동지 (A4 1쪽: 관측 기록표·환산표·단면 그리기, `worksheet.pdf`) |
| `docs/` | 설계 문서와 구현 계획 |
| `tests/` | 은하 모형·별 세기·튜토리얼 계산·문제 로직 테스트 |

## 실행

정적 서버로 폴더를 엽니다.

```bash
python -m http.server 8321 --directory app
```

브라우저에서 `http://localhost:8321/index.html`을 엽니다. (`app/` 폴더만 서비스해야 `.env` 같은 파일이 노출되지 않습니다.)

## 테스트

```bash
node --test "tests/*.test.mjs"
```
