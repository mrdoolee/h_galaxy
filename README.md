# 별을 세어 은하를 그리다 — 허셜의 별 계수법 시뮬레이터

중학 과학 '우리은하' 수업용 웹 시뮬레이터입니다. 학생이 은하 중심의 태양 자리에 서서 망원경을 12방향(30° 간격)으로 돌려 별을 세고, 별의 수를 깊이로 환산해 은하의 단면을 그린 뒤, 나머지 하늘을 자동으로 측정해 3D 원반 지도를 완성하고 해석합니다.

- 허셜의 가정(별은 고르게 분포, 은하 끝까지 관측 가능, 태양은 은하 중심)을 그대로 따릅니다. 실제 은하와의 차이는 수업에서 다룹니다.
- 스마트폰·태블릿 가로 화면 기준. 빌드 도구 없이 정적 파일만으로 동작합니다.

## 구성

| 경로 | 내용 |
|---|---|
| `app/` | 시뮬레이터 (`app/index.html`) |
| `app/js/config.js` | 화면 문구, 해석 질문, 자동 세기 기준(30개) — 선생님이 직접 고칠 수 있음 |
| `worksheet/` | 종이 활동지 (A4 2쪽, `worksheet.pdf`) |
| `docs/` | 설계 문서와 구현 계획 |
| `tests/` | 은하 모형·별 세기 로직 테스트 |

## 실행

정적 서버로 폴더를 엽니다.

```bash
python -m http.server 8321
```

브라우저에서 `http://localhost:8321/app/index.html`을 엽니다.

## 테스트

```bash
node --test "tests/*.test.mjs"
```
